namht Spec Kit

Skill Catalog

A spec-driven software-development assistant that runs on Claude Code. It grounds itself in each repo's Knowledge Base to understand both the business and the code, then supports the whole lifecycle — understand → plan → build → review → QA → operate. Every output is written for both technical and non-technical readers, runs locally, and is protected by a git safety guard.

How to use

  • Slash command — in any Claude Code session, from inside the project folder: /namht-<skill> <args> (e.g. /namht-ask how does the payment flow work?).
  • Plain English — skills auto-activate: just describe the task (e.g. “create user stories for …”).
  • Point-and-click — the Spec Kit UI VS Code extension gives PM/SM a sidebar of cards (no commands or terminal). It also has a 💬 Ask anything card for general, non-repo questions.
  • List everything — /namht-help.
